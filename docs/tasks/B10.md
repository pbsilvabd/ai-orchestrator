## Objective and scope

Return truthful bounded output, exit and stop evidence for a child started without a shell.

Out of scope: Model selection, automatic retry or unsupported process-tree stop guarantees.

## Implementation sequence

1. Define inputs: executable, argument array, cwd, scoped env, separate stream byte caps, deadline and AbortSignal. Define outputs: code/signal/duration, tails, truncation and stop uncertainty.
2. Attach error/exit/close/abort handlers before consuming streams; drain both pipes continuously even after retention caps are reached.
3. Count bytes with buffers; handle UTF-8 truncation deterministically, bounded retained memory and output after abort. Pre-abort must spawn nothing.
4. Reconcile races among spawn error, fast exit, deadline and abort exactly once. On deadline/abort, send SIGTERM, wait `killGraceMs`, then escalate to SIGKILL and detach streams/child handles so inherited pipes cannot keep the supervisor alive. Record only observed root exit; descendants/effects remain unverified.

Map each row ID to named tests or executed experiments and recorded evidence in the
PR. Cover the actual failure boundary, not just a mock returning the expected value.
For docs/research rows, use content, link or experiment verification as appropriate.
Every named variant within a scenario is required, not a choice of one example.

| ID | Scenario | Required observable result |
| --- | --- | --- |
| B10-01 | ENOENT, pre-abort, immediate exit and exit code 7 | No hang; actual spawn/exit status; pre-abort creates no child. |
| B10-02 | Unbounded stdout/stderr and multibyte boundary | Both streams drained, retained bytes bounded and truncation true; no deadlock. |
| B10-03 | Deadline and abort during output | One settled result; timers/listeners cleaned; partial output preserved. |
| B10-04 | Child creates descendant on Windows | Stop evidence describes what was actually observed; no claim all effects reversed or tree stopped. |
| B10-05 | Output split across stream chunks | Retain the exact last N bytes across chunks; decode only complete UTF-8 sequences and report truncation. |
| B10-06 | Child ignores SIGTERM on POSIX | Escalate after grace, settle the runner within bounds, close pipes and report root signal/descendant uncertainty. |

   `node examples/fallback-demo.mjs` from the repo root on Node 24.22.1.

   do not add unit tests that merely repeat prose.

5. Commit, push, open/update the one task PR and verify its URL, base/head and remote
