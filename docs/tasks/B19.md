## Objective and scope

Collect eight bounded diagnostic outcomes with all original failures retained.

Out of scope: Scheduled automation, model ranking, provider calls or replaying uncertain tasks.

## Implementation sequence

1. Implement manual opt-in invocation and isolated bounded runs; accept pinned binary/version and output location.
2. Record each of eight original outcomes, phase and redacted transcript; diagnostic retry is a separate record, never a replacement.
3. Produce a summary that counts pass/fail/not_run and links detailed pulse evidence; missing binary/version is explicit.
4. Enable task-history track only once B17 exists; read actual attempts/testRuns/limitations without rerunning tasks.
