## Objective and scope

Prepare the anonymous OpenCode route for exactly
`opencode/deepseek-v4.1-flash-free`. A missing approval refuses new work before
persistence/workspace/spawn. A future trusted operator approval binds the exact
canonical submit payload, model, zero paid budget, privacy acknowledgement and
expiration; task text cannot supply it. Public catalog GETs are metadata research,
not inference or proof of live availability. No account/key/login inheritance.

The stock MCP server stays passive unless explicitly configured with the new
worker. Free mode fixes its endpoint, public anonymous credential and single
model, bounds time/output/request count, disables auxiliary generation and uses
a service-owned audited local guard for model/HTTP/retry checks. Keep the legacy
loopback fixture builder compatible. Do not implement B20's proposed worker test.

Out of scope: real inference or transmitting repository contents externally in
this session, paid providers, account credentials, routing, model fallback,
automatic retries/replay, automatic merge, sandbox guarantees or M3 completion.
Privacy and provider pricing are external claims, not a permanent guarantee.
