## Objective and scope

Turn the B27 foundation into gates that fail early: ordered jobs, real coverage
thresholds, a macOS leg, a local pre-push guard and schema drift detection. Re-deciding
the foundation (lockfile strategy, pinning scheme) is out of scope.

## Implementation sequence

1. Add native coverage reporting and thresholds taken from the current suite, not from an
   arbitrary number; prove the job fails when a threshold is crossed.
2. Order the pipeline `check -> unit -> smoke` with explicit `needs:` so smoke never runs
   on a failed check.
3. Add the `macos-latest` leg and confirm it passes or is documented as skipped with a
   reason.
4. Add `.githooks/pre-push` (idempotent, no husky dependency) and a drift job running the
   schema checker plus `git diff --exit-code`.
5. Verify end to end, record evidence and publish the PR that closes the issue.

## Required acceptance matrix

| ID | Trigger | Observable result | Forbidden side effects | Verification |

## Validation and evidence to publish

Publish the coverage failure output, the workflow graph showing `needs:`, the macOS leg
result, two consecutive hook runs proving idempotence, and the drift failure diff. Run
`git diff --check` before pushing. Report any leg that was not exercised and why.
