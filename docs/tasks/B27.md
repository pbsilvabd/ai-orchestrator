## Objective and scope

Make the repository reproducible and supply-chain visible: pin the toolchain, pin the
actions, add a single `check` entry point, scan for secrets and audit dependencies.
Coverage thresholds, job ordering, macOS and the pre-push hook belong to B28 and are out
of scope here.

## Implementation sequence

1. Add `packageManager` and generate `package-lock.json` for the existing dependency set;
   confirm `npm ci` succeeds from a clean `node_modules`.
2. Add a `check` script that runs the existing suite and any static gate chosen in the PR;
   prove it exits `0` clean and non-zero with a seeded defect.
3. Pin every action to a commit SHA (keeping the version in a trailing comment) and set
   `permissions: contents: read` per job.
4. Add the redacting secret-scan job plus `.github/dependabot.yml` (actions + npm) and an
   audit step that fails on high severity.
5. Verify on the existing matrix, record evidence and publish the PR.
