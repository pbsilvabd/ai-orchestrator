## Objective and scope

Expose exactly submit/status/result/cancel using the service and configured identity.

Out of scope: HTTP/socket/tunnel, public auth design or using artifact schemas as operation input.

## Implementation sequence

1. Build on the revision verified by B06; use only camelCase service methods and one service instance per home.
2. Define separate input schemas/envelope mapping for all four operations; keep operation validation/authorization in the service. stdout contains protocol only.
3. Bound frame/message input before parsing; handle malformed/unknown method/field, correlation, disconnect and serialization errors with sanitized envelopes.
4. Test protocol discovery/list/call and polling during a fixture worker. On shutdown stop scheduling, retain uncertain evidence and close ownership only when safe.
