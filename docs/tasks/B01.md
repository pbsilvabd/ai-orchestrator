## Objective and scope

Keep unknown keys out of every diagnostic, preserve declared schema paths, document UTF-16 bounds.

Out of scope: Runtime schema wiring, lifecycle changes and full JSON Schema support.

## Implementation sequence

1. Read the checker, its strict schema walk and the actual #8 diff; distinguish schema-controlled text from instance-controlled text.
2. Use a constant unknown-key segment at root, inside objects and inside array items; never truncate and reveal a credential prefix.
3. Preserve deterministic ordering and rejection of unsupported schema keywords; retain the curated subset.
4. Review the existing B01 commit ae729bf rather than reimplement it; resolve integration conflicts without losing B04a/B05 safeguards.
