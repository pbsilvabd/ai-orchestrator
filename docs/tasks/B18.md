## Objective and scope

Inspect and reconcile uncertain tasks without executing them or sharing active ownership.

Out of scope: A worker-callable override, task resume or automatic lock removal.

## Implementation sequence

1. Define maintainer inputs, evidence/actor/reason record and allowed blocked -> failed/cancelled rules separately from ordinary updateTask.
2. Require exclusive maintenance access with no active service/worker; stale owner removal is an explicit verified human recovery action.
3. Implement idempotent inspection/recovery and retention with interruption-safe task/index handling; never prune blocked tasks automatically.
4. Document Windows procedure including process/descendant checks, backup and recovery. On ambiguity preserve state and refuse rather than guess.
