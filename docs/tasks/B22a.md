## Objective and scope

Implement the accepted transactional engine as an opt-in backend without migration.

Out of scope: Migration, default backend switch or widening lifecycle authority.

## Implementation sequence

1. Freeze the current store interface and engine-independent behavior from the accepted ADR; keep JSON available.
2. Implement task/idempotency/artifact/event mutations in one transaction and guard full read-mutate-write with accepted CAS/transaction semantics.
3. Enforce B04a lifecycle and B05 ownership equivalents without introducing a generic reconciliation override.
4. Run the same behavioral suite against both backends; document backend-specific errors and unsupported recovery.
